# readandrip-site — rules for Claude

This repository is readandrip.com, the main Read & Rip site: plain HTML published with GitHub Pages. QB training and the app have separate sections; articles live on learn.readandrip.com (repo `ReadandRipQB/readandrip-learn`).

## Hard rules

- **Work only in `ReadandRipQB/readandrip-site` (and `ReadandRipQB/readandrip-learn` for articles).** Never clone, read, commit to, open pull requests on, or change any other repository, in particular the Read & Rip app repository and `ReadandRipQB/readandripqb`. Never change readripqb.com, the website the app lives on. Linking to it is fine.
- **Every change goes through a pull request. Never push to `main`, never merge, never force-push, never delete branches or files Zach made.** Zach reviews each pull request and merges it himself; merging is what publishes.
- If a task ever seems to need another repository or the app's site, stop and ask Zach.

## Writing rules

- Zach's voice: a coach in a film room. Specific, direct, plain words.
- The app runs in any web browser and on Google Play. Never say App Store, iOS or iPhone.
- Never claim liability insurance. Don't add claims Zach hasn't confirmed (for example, that training clients get the app).
- Booking links are Calendly (`calendly.com/zachtrainor-readripqb/...`); check an event is active before linking it.
